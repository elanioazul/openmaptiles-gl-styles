# What is

A self contained styles management app for openmaptiles GL styling

# What for

GL webmapping demands intense vector tile data and styling this data is complex
This app lift a style editor app named [Maputnik](https://github.com/maplibre/maputnik) and a [Martin](https://maplibre.org/martin/) server.
The second serves geodata, the first style it according to [MapLibre Style Spec](https://maplibre.org/maplibre-style-spec/).
